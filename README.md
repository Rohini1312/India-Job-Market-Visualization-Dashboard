# India Job Market Visualization Dashboard Using Python

## Project Overview

This project develops an India Job Market Visualization Dashboard using Python to analyze job market data and generate meaningful insights about job opportunities, skills, experience levels, locations, companies, and salary trends.

## Objectives

- Analyze job opportunities across different locations
- Identify in-demand skills
- Compare job distribution by company
- Analyze experience-level requirements
- Analyze job types and employment opportunities
- Compare salary trends across locations
- Present insights through an interactive dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Key Features

- Total Jobs KPI
- Total Companies KPI
- Total Locations KPI
- Average Salary KPI
- Jobs by Location
- Jobs by Company
- In-Demand Skills Analysis
- Experience Level Analysis
- Job Type Analysis
- Salary by Location
- Salary Distribution
- Interactive Filters
- CSV Data Download
- Business Insights

## Visualizations

- Jobs by Location
- Jobs by Company
- Top In-Demand Skills
- Jobs by Experience Level
- Jobs by Job Type
- Salary by Location
- Salary Distribution
- Interactive Job Market Dashboard

## Conclusion

The project converts job market data into clear and meaningful visual insights using Python. The dashboard helps understand job opportunities, demanded skills, experience requirements, company distribution, and salary trends across different locations in India.

> **Note:** The dataset used in this project is synthetic/demo data created for educational and internship purposes and does not represent real-time India job-market statistics.
